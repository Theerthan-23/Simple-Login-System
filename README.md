# Simple Python Login System

A basic login system in Python that allows users to log in with a username and password. It is designed for beginners who want to practice Python dictionaries, loops, and conditional statements.

---

## Features

- Supports multiple users using a Python dictionary.
- Validates user ID and password.
- Allows **3 login attempts** before blocking further attempts.
- Provides clear feedback for incorrect username or password.
- Case-insensitive usernames (optional enhancement).
- Password input hidden using `getpass` (optional enhancement).

---

## How to Use

1. Clone the repository or download the code.
2. Run the Python script:

```bash
python login_system.py
3. Enter your user ID and password when prompted.

4. You have 3 attempts to enter the correct credentials
